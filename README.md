# 원

**Language Models · Long-Term Memory · Retrieval-Augmented Generation**

장기 대화에서 언어 모델이 정보를 **기억하고, 검색하고, 활용하는 방식**에 관심이 있습니다.
논문을 읽고 핵심 아이디어와 실험 결과를 정리하며, 관련 프로젝트를 코드로 기록합니다.

## Research Interests

- **Long-Term Memory** — 장기 대화의 기억 관리, 사용자 정보 갱신, 개인화.
- **Retrieval-Augmented Generation** — 검색과 생성의 연결, 벡터 검색, 근거를 활용한 답변.
- **Memory Evaluation** — 정보 회상, 여러 대화의 추론, 시간 정보와 답변 유보의 평가.
